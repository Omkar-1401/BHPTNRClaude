# gw_remnant energy-driven scaling fit (gw_remnant_energy, form=`linear`)

Switchless, 5 free parameters.  The *only* time-dependence is the mass the binary has radiated away.  No angular-momentum coordinate, no logistic gate.

`phi0` is solved in closed form at every evaluation (`phi0 = arg(sum(h_NR * conj(h_model)))`) rather than fitted: the (t0_nr, phi0) alignment valley is flat enough that per-q optima scatter by O(pi) between adjacent q, which is unregressable in nu.

## Loss coordinate (gw_remnant)

```python
# RemnantMassCalculator(t_bhpt, {(2,2): h22, (2,-2): conj(h22)}, q,
#                       E_initial=0, L_initial=0, M_initial=1)
dE/dt = (1/16*pi) * sum_lm |dh_lm/dt|**2      # calc.E_dot
E(t)  = cumtrapz(dE/dt, t)                    # calc.Eoft, units of M
M(t)  = 1 - E(t)                              # calc.Moft (Bondi mass)
dE(t)    = E(t) - E(T_ANCHOR)
m_hat(t) = M(t) / M(T_ANCHOR)
```

## Model equations

```python
alpha(t) = alpha_i + alpha_E * dE(t)
beta(t)  = beta_i  + beta_E  * dE(t)
tau(t) = t0_nr + integral_{T_ANCHOR}^{t} beta(t') dt'
h_model(tau(t)) = alpha(t) * exp(i*phi0) * h_BHPT(t)
```

Pure mass rescaling predicts alpha_E/alpha_i = beta_E/beta_i = -1/M(T_ANCHOR) ~ -1.006.

## Regression

```python
nu(q) = q / (1 + q)**2
# Anchored at nu->0:  alpha_i, beta_i
# Free:               alpha_E, beta_E, t0_nr, phi0
```

The couplings are deliberately UNANCHORED: dE -> 0 and m_hat -> 1 in the
test-particle limit already enforce the PP limit, and E(t) carries its own
nu-scaling (E_rad ~ nu^2), so the couplings should be nearly nu-flat.
